# НишаБух — сайт

Навигатор для свободных бухгалтеров: ниши с рейтингом и спросом, оффер, боты и воронки, заявки, реклама, партнёрки, план запуска.

**Рабочий адрес сайта: <https://nishabuh.ru/>** — домен на Beget, зарегистрирован и делегирован 15.09.2026; файлы лежат в `public_html` сайта `nataliil78.beget.tech`. Пока бесплатный сертификат Let's Encrypt выпускается, сайт открывается по `http://nishabuh.ru/`; после выпуска — по `https://nishabuh.ru/`.

## Как открыть

Двойной клик по `index.html`. Меню — слева (на телефоне сверху). Ничего устанавливать не нужно: это статические файлы.

## Состав

```
index.html            — главная (баннер, разделы, преимущества)
start.html            — Старт с нуля (пошаговый проводник)
niches.html           — Нишедатель (рейтинг, спрос, поиск клиентов)
offer.html            — Конструктор оффера
bots.html             — Боты и воронки (+ пять шагов воронки)
feed.html             — Заявки (лента объявлений)
ads.html              — Реклама и продвижение (бенчмарки)
partners.html         — Партнёрки
plan.html             — План 30 дней (+ вопросы и ответы)
funnel.html, faq.html — перенаправления на объединённые страницы
styles.css            — стили
app.js                — логика: меню, данные, автосинхронизация, оформление
inter-1…7.woff2       — шрифт Inter (локально, SIL OFL)
nishabuh-data.json    — база: ниши, спрос, партнёрки, заявки
tools/                — скрипты обновления базы (для хостинга и для VPS)
```

Все файлы лежат в одной папке — так загрузка на хостинг делается одним действием, без создания вложенных папок.

## Как править

- **Тексты** — в соответствующем `.html`.
- **Меню и разделы** — `app.js`, структура `DEPTS`/`NAV` (при правке меню перегенерируются шапка и сайдбар).
- **Стили и цвета** — `styles.css`, переменные в `:root`; акцент — `--accent`; шрифты — блоки `@font-face` и файлы `inter-*.woff2`.
- **Данные (ниши, спрос, партнёрки, заявки)** — `nishabuh-data.json`.

## Оформление (тема и цвета)

Кнопка **«Оформление»** внизу меню (на телефоне — внизу слева): светлая/тёмная тема, шесть акцентных цветов, размер текста, сброс. Выбор хранится в браузере (`localStorage`) и действует на всех страницах.

## Реальные цифры спроса — что нужно

Сейчас в базе демо-значения (поле `demand`: показы Вордстата, динамика, вакансии hh). Чтобы шли реальные числа, нужен **сервис обновления базы**: он пишет значения в JSON, а сайт подхватывает их сам (при открытии и далее каждые 10 минут).

1. **Доступ к источникам**
   - **Вордстат** — только официальный API Яндекса (Яндекс.Директ API): аккаунт, OAuth-приложение, токен. Отдаёт частотность по фразам.
   - **hh.ru** — публичный API вакансий (`https://api.hh.ru/vacancies?text=…`, поле `found`). Ключ не нужен, но hh блокирует **серверные адреса**: проверено, что с хостинга приходит 403 при любом User-Agent. Работает при запуске с домашнего интернета.
   - **«Работа России»** — открытый API портала `opendata.trudvsem.ru` (поле `meta.total`). Ключ не нужен и доступен с хостинга, поэтому скрипт использует его автоматически, когда hh недоступен.
2. **Место, где скрипт работает по расписанию** — VPS/хостинг с cron (достаточно раз в сутки) или обычный компьютер с планировщиком. Скрипт: `tools/update-demand.mjs`.
3. **Публикация файла** — скрипт сохраняет `nishabuh-data.json` в папку сайта; либо откройте сайт ссылкой `index.html?data=https://адрес/nishabuh-data.json`.
4. **Оговорки** — Вордстат показывает частотность запросов, hh — число вакансий; это сигналы спроса, а не число клиентов. Дата обновления видна в карточке ниши («обновлено N минут назад»); после первого реального прогона метка «демо» сменится на «реальные данные».

## Публикация

Сайт **уже опубликован на Beget**: <https://nishabuh.ru/> (после выпуска сертификата Let's Encrypt — по https, до этого — по http). Хостинг: сайт `nataliil78.beget.tech/public_html`, домен `nishabuh.ru` привязан к этому сайту. Сборка не нужна — папку загружают целиком, главная — `index.html`. На хостинге автосинхронизация базы работает сразу. Подойдёт и любой другой статический хостинг (GitHub Pages, Netlify и т. п.).


## Пошагово: как включить обновление в реальном времени

Клиентская часть уже работает: сайт забирает базу при открытии и далее каждые 10 минут (интервал — `SYNC_PERIOD` в `assets/app.js`). Нужно только наполнять базу реальными числами.

1. **Проверить скрипт вручную**
   ```
   node tools/update-demand.mjs "nishabuh-data.json"
   ```
   В консоли — список ниш и число вакансий hh по каждой.
2. **Выбрать, где будет работать скрипт**
   - *Домашний компьютер*: установить Node.js 18+, создать задачу в Планировщике заданий (Windows) или строку в cron (Linux/macOS), например ежедневно в 9:00.
   - *Сервер 24/7 (VPS)*: установить Node.js, скопировать сайт и скрипт, поставить в cron:
     `0 6 * * * cd /var/www/nishabuh && node tools/update-demand.mjs nishabuh-data.json >> /var/log/nishabuh-demand.log 2>&1`
3. **Обновлённая база должна попадать в папку сайта** — скрипт пишет `nishabuh-data.json`; при размещении на хостинге перезаливайте файл (или дописать выгрузку по FTP — отдельная задача).
4. **Вордстат (частотность)** — только официальный API Яндекса: OAuth-приложение + токен с правами `direct:api`, хранить в переменной окружения `WF_TOKEN`. После получения токена в скрипт добавляется запрос частотности.
5. **Если hh отвечает 403** — указать контакт в User-Agent (`HH_UA`), запускать с домашнего IP или зарегистрировать приложение у hh.
6. **Проверка результата** — в карточке ниши: «обновлено только что» и метка «реальные данные» вместо «демо».

Подробная версия с картинками шагов — в отдельном документе «НишаБух — обновление данных в реальном времени (по шагам).html».


## Обновление на хостинге (PHP + cron) — без VPS и без Node.js

Для обычного виртуального хостинга (например, Бегет) есть версия обновлятора на PHP: `tools/update-demand.php`. Ей нужны только PHP и curl — оба есть на любом хостинге.

1. Загрузите папку `tools` на хостинг вместе с сайтом.
2. Создайте файл настроек из образца `tools/update-demand.config.sample.php` → `update-demand.config.php`, положите его **вне** `public_html` и впишите свой e-mail в `hh_ua`.
3. Проверьте запуск вручную:
   ```
   php tools/update-demand.php public_html/nishabuh-data.json /путь/вне/public_html/update-demand.config.php
   ```
4. Добавьте cron-задание (раз в сутки достаточно):
   ```
   0 6 * * * php /home/uXXXXXXX/домен/public_html/tools/update-demand.php /home/uXXXXXXX/домен/public_html/nishabuh-data.json /home/uXXXXXXX/update-demand.config.php
   ```
5. Через сутки откройте сайт: в карточке ниши — «обновлено N часов назад» и метка «реальные данные».

Скрипт запускается только из командной строки, меняет лишь файл базы и делает резервную копию `nishabuh-data.json.bak`. Частотность Вордстата включается токеном в настройках (`wf_token`).

Подробный план по шагам — в документе «НишаБух — размещение на хостинге и реальные цифры.html».


## Регистрация в Бегете — коротко

1. Аккаунт: beget.com/ru → «Войти» → «Регистрация» (e-mail, телефон, пароль).
2. Хостинг: beget.com/ru/hosting/virtual — для сайта достаточно минимального тарифа (сайт ~0,6 МБ, база данных не нужна).
3. Домен: beget.com/ru/domains или в панели раздел «Домены и поддомены» → «Создать новый сайт для каждого домена». Для домена из другого места — NS-серверы ns1.beget.com, ns2.beget.com, ns1.beget.pro, ns2.beget.pro.
4. Панель управления: cp.beget.com. Файлы сайта — в папке `public_html` домена.
5. Файлы: загрузить содержимое папки `НишаБух для Бегета` (index.html должен лежать в корне public_html).
6. HTTPS: бесплатный сертификат Let's Encrypt из панели + перенаправление на https.
7. Задание по расписанию: раздел CronTab → «Составить задание вручную», команда вида
   ```
   /usr/local/bin/php ~/домен/public_html/tools/update-demand.php ~/домен/public_html/nishabuh-data.json ~/update-demand.config.php
   ```
   расписание `0 6 * * *` (каждый день в 06:00). Проверить запуск можно во вкладке «Запустить скрипт».

Официальная справка Бегета: CronTab — beget.com/ru/kb/manual/crontab, раздел «Сайты» — beget.com/ru/kb/manual/sajty, услуги и баланс — beget.com/ru/kb/manual/upravlenie-uslugami, домен другого регистратора — beget.com/ru/kb/how-to/domains/other-registrar-domain-2, SSL — beget.com/ru/ssl/letsencrypt.

Подробная версия со ссылками — в документе «НишаБух — регистрация в Бегете пошагово.html».


## Если кабинет на Бегете уже есть

Регистрировать аккаунт не нужно, и покупка хостинга может не понадобиться: в тарифах Бегета обычно входит несколько сайтов.

1. Проверьте в панели (cp.beget.com) три раздела: «Управление услугами» (активен ли хостинг, есть ли свободный слот для сайта, срок оплаты), «Домены и поддомены» (есть ли домен), «Сайты» (какие сайты уже созданы).
2. Если слот есть — просто добавьте сайт под наш домен («Создать новый сайт для каждого домена») и загрузите файлы в его public_html.
3. Если домен уже в этом аккаунте — NS-серверы трогать не нужно.
4. Дальше как обычно: SSL Let's Encrypt, файл настроек вне public_html, CronTab на `0 6 * * *`.
5. Услуга истекла — продлить в «Управлении услугами».

Не нужно: второй аккаунт, второй хостинг при свободном слоте, база данных, CMS, перенастройка NS для «своего» домена.

Документ: «НишаБух — кабинет на Бегете уже есть.html» (таблица решений по шести ситуациям + 5 шагов).


## Если на балансе долг (например, −20 ₽)

Минус у Бегета ведёт к автоматической блокировке услуг: списание идёт ежесуточно, и если суммы не хватает — услуги отключаются (в выходные списывают даже в минус, поэтому небольшие долги часто появляются в начале недели).

1. Панель cp.beget.com → раздел «Оплата» → «Пополнить счёт». Внести сумму **с запасом** (закрыть минус + месяц тарифа), а не ровно долг.
2. «Управление услугами»: проверить, что баланс положительный и хостинг активен; если была блокировка, услуга включается в течение нескольких минут, иначе — тикет в «Помощь и поддержка».
3. «Оплата» → «Автоматический платёж»: привязать карту, списание за 3 дня до нуля. Сумма фиксируется по составу услуг на момент подключения.
4. «Домены и поддомены»: проверить срок и автопродление домена — он продлевается отдельно от хостинга.
5. Дальше — размещение сайта: добавить сайт под домен, загрузить файлы, SSL, CronTab.

Оплатить можно и без входа в кабинет: на beget.com кнопка «Оплата» вверху, по логину аккаунта или домену.

Документ: «НишаБух — долг на Бегете 20 рублей что делать.html».
