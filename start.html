Проведу за руку: от нуля до первых заявок

Нажимайте шаг — он раскрывается. Где возможно, сайт делает сам (копирует текст, собирает файлы, считает метки), где нужно — пишет точно, куда нажать. Отметки о выполнении сохраняются в браузере.

Выполнено 0 из 10 шагов

Мастер

Соберите стартовый пакет за один клик

Выберите нишу — и сайт за один клик соберёт папку для старта: что говорить клиентам, что подарить за контакт, сколько брать за услуги, где искать клиентов и что напишет бот. Ничего печатать не нужно — забирайте и работайте.

Пакет собирается в браузере и никуда не отправляется. Токены и пароли здесь не нужны.

Десять шагов

            
Нажмите на шаг — откроются действия

            
Метка авто — сайт делает сам; руками — с точной подсказкой, куда нажать.

          

          


            

              Шаг 1. Выберите нишу авто
              

                
Рейтинг и спрос сайт считает сам — вам остаётся выбрать.

                
    
                  
  1. Откройте «Нишедатель» (кнопка ниже).
    2. 
                  
  2. Нажмите один из профилей: «Максимум дохода» или «Быстрый старт».
    3. 
                  
  3. Посмотрите топ-3 в списке и нажмите «Открыть нишу» у лучшей.
    4. 
                  
  4. Внутри прочитайте блок «Спрос онлайн» — цифры уже готовы.
    5. 
                

                
Открыть нишедатель

                
              

            


            

              Шаг 2. Получите готовый оффер авто
              

                
Сайт копирует оффер выбранной в мастере ниши — вставляйте в лендинг и соцсети.

                
    
                  
  1. Нажмите «Скопировать оффер» — текст уже в буфере.
    2. 
                  
  2. Вставьте в лендинг (заголовок — первая строка) и в описание профиля.
    3. 
                

                
Открыть конструктор оффера

                
              

            


            

              Шаг 3. Сделайте лендинг руками
              

                
    
                  
  1. Откройте tilda.cc и зарегистрируйтесь (есть бесплатный тариф).
    2. 
                  
  2. Кнопка «Создать новый сайт» → выберите шаблон «Лендинг».
    3. 
                  
  3. В первый блок вставьте скопированный оффер (Шаг 2).
    4. 
                  
  4. Добавьте блок «Форма» → поля: имя, телефон/Telegram → подпись «Оставить заявку».
    5. 
                  
  5. Справа вверху нажмите «Опубликовать» → скопируйте ссылку сайта.
    6. 
                

                
Совсем без конструктора можно начать с профиля в Telegram — лендинг добавите позже.

                
              

            


            

              Шаг 4. Заведите профиль или канал в Telegram руками
              

                
    
                  
  1. Откройте Telegram → меню «≡» слева вверху → «Создать канал».
    2. 
                  
  2. Имя — по нише (например, «Бухгалтер для селлеров»), тип — «Публичный».
    3. 
                  
  3. Получите ссылку вида t.me/имя и вставьте её в лендинг.
    4. 
                  
  4. Заведите закреплённый пост с оффером из Шага 2.
    5. 
                

                
              

            


            

              Шаг 5. Создайте бота руками конфиг — авто
              

                
    
                  
  1. В Telegram в поиске наберите @BotFather → нажмите Start.
    2. 
                  
  2. Отправьте команду /newbot.
    3. 
                  
  3. Введите имя бота (как в списке), затем username, оканчивающийся на bot.
    4. 
                  
  4. BotFather пришлёт токен — скопируйте его и сохраните в надёжном месте, никому не отправляйте.
    5. 
                  
  5. Скачайте конфигурацию кнопкой ниже — остальное перенесёте в платформу ботов.
    6. 
                

                
Страница «Боты и воронки»

                
              

            


            

              Шаг 6. Настройте, куда приходят заявки руками
              

                
    
                  
  1. Решите, куда падают заявки: ваш Telegram, почта или таблица.
    2. 
                  
  2. Впишите этот адрес в поле leadsTo в файле конфигурации бота (или в конструкторе на странице «Боты»).
    3. 
                  
  3. В форме на лендинге укажите тот же адрес получателя.
    4. 
                  
  4. Проверьте: отправьте себе тестовую заявку и убедитесь, что она дошла.
    5. 
                

                
              

            


            

              Шаг 7. Получите UTM-метку для рекламы авто
              

                
Сайт соберёт метку под вашу нишу — она нужна, чтобы видеть, откуда пришла заявка.

                
    
                  
  1. Нажмите «Скопировать UTM».
    2. 
                  
  2. В рекламном кабинете вставьте её в конце ссылки лендинга.
    3. 
                

                

                
              

            


            

              Шаг 8. Подключите 2–3 партнёрки руками
              

                
    
                  
  1. Откройте раздел «Партнёрки» (кнопка ниже).
    2. 
                  
  2. Выберите программы со значком «проверено по открытым источникам».
    3. 
                  
  3. Зарегистрируйтесь и скопируйте реферальную ссылку.
    4. 
                  
  4. Добавьте ссылку в профиль и на лендинг (можно в отдельный блок «Полезное»).
    5. 
                

                
Открыть партнёрки

                
              

            


            

              Шаг 9. Запустите рекламу на заявки руками
              

                
    
                  
  1. Откройте Яндекс.Директ → «Создать кампанию» → «Мастер кампаний».
    2. 
                  
  2. Цель — «Заявки», посадочная страница — ваш лендинг из Шага 3.
    3. 
                  
  3. Регион и бюджет — по бенчмаркам из раздела «Реклама» (стартовый сценарий ≈60 000 ₽/мес).
    4. 
                  
  4. Не ограничивайте показы на старте и не закрывайте CPA — дайте кампании набрать данные.
    5. 
                  
  5. Ссылки размечайте UTM из Шага 7.
    6. 
                

                
Бенчмарки и чек-лист рекламы

                
              

            


            

              Шаг 10. Первые клиенты и диагностики лента — авто
              

                
    
                  
  1. Откройте «Заявки» — там уже собраны объявления «кто ищет бухгалтера».
    2. 
                  
  2. Ответьте на 5 — предложите бесплатную 20-минутную диагностику.
    3. 
                  
  3. Проведите 10 диагностик: покажите чек-лист находок и назовите цену проблемы.
    4. 
                  
  4. Отмечайте шаги в разделе «План 30 дней» — прогресс сохраняется.
    5.

Что сайт делает сам

              
    
                
  • Считает рейтинг ниш и спрос, показывает заявки из ленты.
    • 
                
  • Собирает оффер, стартовый пакет, UTM-метку и конфигурацию бота — файлами.
    • 
                
  • Хранит отметки о шагах, весах и плане прямо в браузере.
    • 
              

            

            

              
Что придётся сделать руками

              
    
                
  • Зарегистрироваться в сервисах (Telegram, лендинг, платформа ботов, кабинет рекламы).
    • 
                
  • Создать бота в BotFather и сохранить токен.
    • 
                
  • Оплатить рекламный бюджет — цифры-ориентиры в разделе «Реклама».
    •
